# An-lisis-de-Se-ales-en-el-Dominio-del-Tiempo-y-la-Frecuencia
Análisis experimental y computacional de señales periódicas en el dominio del tiempo y la frecuencia. Se estudian señales senoidales, triangulares, cuadradas y de pulso mediante FFT, MATLAB/Octave y Series de Fourier, utilizando datos obtenidos de un osciloscopio y comparando resultados teóricos y experimentales.
